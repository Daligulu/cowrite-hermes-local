# Exa vs 豆包 Custom 中文搜索对照测试

- 时间：2026-07-29 16:48 CST
- 查询数：10
- 每个后端每条查询最多 10 个结果
- 豆包：Custom、默认权威过滤关闭、4 QPS 本地队列
- Exa：Agent Reach `web_search_exa`
- 社区 MCP / AI 交叉核查层：未使用
- 原始正文：未归档；仅保留聚合指标与人工判断

## 结果

- 成功率：豆包 10/10；Exa 10/10（其中 1 次 JSON 解析失败，重试成功）
- 平均延迟：豆包 2204ms；Exa 2180ms
- 中位延迟：豆包 2164ms；Exa 2040ms
- 返回结果：双方均 100 条
- 每查询平均唯一域名：豆包 8.4；Exa 5.7
- 具有发布时间：豆包 100/100；Exa 43/100
- Top 5 官方域名命中（启发式）：豆包 11/50；Exa 27/50

“官方域名”指标只按域名白名单计算，未使用豆包自带 `AuthInfoDes`，因此不能等同于豆包权威等级评分。

## 人工评估

- Exa 明显领先：5 题
  - 最新 AI 政策
  - 飞书官方功能
  - 北京生成式 AI 备案
  - Hermes 官方仓库与文档
  - Agent Skill 开源项目
- 豆包明显领先：2 题
  - 抖音百科、火山如意、豆包数据源
  - 国内 AI 副业合规风险的中文媒体覆盖
- 基本持平或双方都需二次核验：3 题
  - 豆包价格与版本官方资料
  - 国内 Agent 创业融资
  - AI 投顾监管

## 结论

1. Exa 在精确命中 GitHub、飞书、网信办、火山引擎等一手页面方面更稳。
2. 豆包覆盖的中文域名更多，发布时间字段更完整，国内媒体与字节生态召回更强。
3. 豆包默认结果中仍有聚合站、百科和 SEO 页面；政策、医疗、金融查询应加 `--auth-level 1`。
4. 两者延迟接近，不应因速度单独替换任一后端。
5. 推荐路由：
   - 精确官网、技术文档、GitHub、海外资料 → Exa
   - 中文新闻、国内公司、行业动态、字节生态 → 豆包 Custom
   - 高风险中文事实 → 豆包 `auth-level=1` + Exa 交叉核对原始 URL
