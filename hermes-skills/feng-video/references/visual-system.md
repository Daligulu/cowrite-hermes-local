# 视觉系统 · 16:9 峰峰知识视频

## 画布与安全区

- 1920×1080，30fps。
- 主内容安全区：x=100–1820，y=70–900。
- 字幕安全区：x=180–1740，y=900–1030。
- 右上品牌区只放当前账号标识；不得复制参考视频水印。
- 峰峰出现时必须为其动作与字幕分别预留空间。

## 白底动画层

- 背景：`#FBFAF7` 或纯白；不使用大面积渐变。
- 主轮廓：`#1D2633`，2–6px，允许轻微手绘抖动。
- 语义强调：蓝 `#2D6CDF`、青 `#42B8B0`、绿 `#49A96D`、黄 `#F1C75B`、橙 `#ED9148`、紫 `#7357B5`。
- 每场最多 3 个主强调色，颜色代表语义模块，不做装饰彩虹。
- 主体占 45–75%；连续留白不少于 20%。
- 阴影只用于分离层级，透明度低于 16%。

## 录屏层

- 保留真实暗色终端/编辑器。
- 可增加 16–28px 圆角裁切、轻暗角和 1–2px 暖金高亮边。
- 红箭头只标一个错误/结论；绿色用于通过状态。
- 小字录屏必须裁切或推近，使关键内容在1080p暂停时可读。
- 删除/遮盖密钥、账号、私人路径、通知和无关窗口。

## 文字层级

- 字体：Noto Sans CJK SC / 思源黑体。
- 章节标题：88–120px，700–900，蓝色。
- 主结论：64–92px，700–900。
- 物件标签：28–40px，600–800，2–6字。
- 说明文字：30–42px，行距1.25–1.4。
- 底部字幕：42–52px，700；每块8–18字，最多两行。
- 字幕底：半透明深灰圆角条或3–5px深色描边；不要两者都过重。
- 所有准确中文都由HTML/SVG/Canvas渲染。

## 峰峰人物层

人物外观只引用 `feng-ip`。

- 3/4身或全身优先；避免纯头像。
- 场景占比按动作决定，通常画面面积8–18%。
- 人物可在左/右三分区或知识对象旁，不固定右下角。
- 角色入场动作必须绑定语义：指、拉、推、投、接、看、写、选择、验收。
- 视频中不得出现原参考视频女孩、原机器人造型或原IP服装。

### 人物与场景融合

- 需要握、推、按、接、搬、转、写、坐、走等精确接触或承重时，优先整帧生成，不把高精人物PNG后贴到独立场景对象上。
- 人物通常占画面宽度12–20%；复杂动作可略增，但不得遮住动作目标、接触点、运动路径和结果状态。
- 双手必须分别写明接触对象，手指与物件之间应有可信遮挡；“手在附近”不算操作。
- 人物、目标对象、运动路径和结果必须共享一个清晰主方向，并形成动作前→动作中→动作后连续因果链。
- 人物、对象和环境共享线条粗细、光源、阴影方向、透视、接地和空间层级；峰峰可轻微手绘化，但身份、暖肤色和服装颜色不能漂移。
- 白底透明化只用于无接触叠加镜头；涉及物理操作时，透明化不能替代整帧生成。
- 用户认可校准图与详细门禁见 `character-scene-integration.md`。

## 动效层

- 画面整体尽量稳定；物件做动作。
- 重要动词必须映射到可见状态变化。
- 默认缓动：`power2.out`、`back.out(1.4)`、`sine.inOut`。
- 单次入场0.25–0.7秒；可读停留不少于0.8秒。
- 同一场最多一个主运动方向。
- 连续三场不能使用同一“卡片淡入”方式。

## 字幕与人物避让

- 字幕矩形和人物动作边界不得相交。
- 角色在底部时，字幕上移或缩短，不覆盖手部和互动对象。
- 录屏底部已有状态栏时，字幕使用独立深色条，不与原UI混在一起。
