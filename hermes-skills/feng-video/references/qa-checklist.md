# QA Checklist

## 内容

- [ ] Hook在前5–12秒给出冲突或反常识结论。
- [ ] 前15%时长内说明挑战与观看价值。
- [ ] 概念解释、实施过程、证据链和结论完整。
- [ ] 所有数据、代码和测试均来自真实素材；模拟内容已明确标注。
- [ ] 结尾回收前文，不引入新核心概念。

## 画面

- [ ] 白底动画与真实录屏交替合理。
- [ ] 每场只有一个视觉任务。
- [ ] 一场通常1个主物件、1条主路径、2–4个辅助对象。
- [ ] 连续3场没有相同模板、布局和入场方式。
- [ ] 每个重要动词都有对象级动作。
- [ ] 章节卡0.8–1.5秒且只放章标题。
- [ ] 代码/终端关键区域在1080p暂停时可读。
- [ ] 无未经授权的参考视频截图、角色、Logo和水印。

## 峰峰

- [ ] 人物外观来自`feng-ip`，不是重新杜撰。
- [ ] 无眼镜，深蓝黑短发，白hoodie双抽绳，深海军蓝夹克，暖肤色。
- [ ] 只在约15–25%场景出现。
- [ ] 每次承担操作、提问、观察、选择、反应或验收。
- [ ] 不固定贴在右下角，不遮挡字幕、数据或手部动作。
- [ ] 无模型生成乱码文字。
- [ ] 需要操作的镜头中，每只关键手都有明确接触对象，不存在捏空气、悬空指向或穿模。
- [ ] 抓握、按压、位移、痕迹、连接、承重、开合或步态等与当前动词匹配的状态变化可见。
- [ ] 动作前状态→人物动作→对象响应→结果状态形成连续因果链，不出现漂浮或无来源变化。
- [ ] 人物通常占画面宽度12–20%，不遮挡动作目标、接触点、运动路径和结果。
- [ ] 人物、对象与环境共享线条、光影、透视和空间层级，不像不同风格的独立图层。
- [ ] 需要精确接触时使用整帧生成；透明PNG叠加只用于观察、思考、指向和反应。
- [ ] 无白色矩形、硬裁切、透明白边、人物素材框、身体漂浮或环境穿模。

## 人物动作时序

- [ ] 每个峰峰场景声明 `motion_strategy` 和五阶段 `action_phases`。
- [ ] 单张静态人物只承担无接触手势；简单按压才允许 `anchored-micro-motion`。
- [ ] 转动、推拉、搬运、承重、行走和递接使用绑定动画、至少3姿势序列、整帧场景或连续视频。
- [ ] 动作顺序联系表覆盖预备、首次接触、操纵25%/50%/75%、释放和结果。
- [ ] 接触在整个操纵阶段持续成立，没有脱手、穿手、漂浮、脚滑或突然换姿势。
- [ ] 身体动作先发生，对象随后响应，结果最后出现并保留可读停留。
- [ ] `scripts/validate_action_timeline.py storyboard.json --strict`退出0。

## 字幕与文字

- [ ] 字幕8–18字/块，最多两行。
- [ ] 字幕与SRT/VTT语义、时间一致。
- [ ] 中文全部代码渲染，逐字检查。
- [ ] 标签2–6字并与具体物件绑定。
- [ ] 字幕、人物、UI和安全区不碰撞。

## 动效

- [ ] 普通动画场2.5–8秒，录屏证据6–15秒。
- [ ] 视觉语义切换中位约4–7秒。
- [ ] 对象入场0.25–0.7秒，可读停留≥0.8秒。
- [ ] 不是整片卡片淡入淡出的PPT节奏。
- [ ] 章节转折有短呼吸，重点信息不一闪而过。

## 声音

- [ ] `VOICE_PROFILE.json`能从 `VOICE_PRESETS.json`解析为唯一Profile。
- [ ] 默认Profile为 `feng-yunxi`，对应 `zh-CN-YunxiNeural`、速度1.08和 `provider_preset`。
- [ ] 音色只通过Profile选择，HTML、分镜和渲染器未写死Provider或Voice ID。
- [ ] 统一生成器输出48kHz `voiceover.wav`、MP3、字幕、voice-qa和pronunciation-log。
- [ ] 首、中、尾字幕同步。
- [ ] 旁白约300–340字/分钟，或记录偏离原因。
- [ ] BGM不盖人声，SFX不连续轰炸。
- [ ] 最终响度规范化，峰值≤-1 dBTP。
- [ ] Profile和注册表不含API Key、Token、Cookie、密码或连接凭据。

## 文件与交付

- [ ] `validate_package.py --strict`退出0。
- [ ] `ffprobe`验证MP4时长、1920×1080、30fps和音频流。
- [ ] 草稿、最终MP4、联系表和REVIEW_REPORT均存在。
- [ ] 项目文件可复用，不只有成片。
