# 状态、单一事实来源与原创门禁

## storyboard.json 是单一事实来源

所有下游产物必须从 `storyboard.json` 派生：

- `STORYBOARD.md` 是人类可读视图，不得反向覆盖 JSON。
- 峰峰资产清单、录屏清单、字幕、BEAT_MAP、MOTION_MAP、HTML场景和剪辑EDL均引用 `scene.id`。
- 修改镜头时先改 JSON，再只重建受影响的场景。
- 禁止在多个文件维护互相漂移的独立时间轴。

每个场景至少保留：来源文稿范围、旁白、字幕、起止时间、视觉模板、资产模态、具体物件、动作链、峰峰职责、证据来源和转场。

## P0–P8 状态

`work/state.json` 记录：

- P0 初始化与依赖；
- P1 文稿结构化；
- P2 原创转译；
- P3 章节与口播；
- P4 镜头路由；
- P5 峰峰资产；
- P6 真实录屏；
- P7 配音字幕；
- P8 时间线、渲染与打包。

每阶段记录 `status`、输入hash、输出hash、开始/结束时间和错误摘要。重跑时只重建输入hash变化或输出缺失的阶段。

## 原创门禁

`originality-plan.json` 对每个场景填写：

```json
{
  "scene_id": "s001",
  "borrowed_grammar": "反常识Hook + 单一证据",
  "new_metaphor": "针对当前文稿重新设计的具体物件和动作",
  "reference_asset_used": false,
  "difference": "人物、文案、物件、镜头顺序和构图均为新设计"
}
```

禁止字段或描述：

- “照参考视频X分X秒做”；
- “同样的角色换成峰峰”；
- 直接使用目标视频帧、截图、音乐、字幕或插画作为生成参考；
- 一一对应复刻原视频镜头顺序。

## 证据门禁

声称真实执行结果的场景必须记录来源：

- 真实代码执行：命令、退出码、stdout/stderr摘要、环境；
- 产品操作：原始录屏路径和复现步骤；
- 数据结论：数据文件、查询或报告路径。

缺少来源时只能标记 `illustrative` / “示意”，不得标为 `real-screen` 或 `result-proof`。

## 打包隐私

公开制作包排除：

- `feng-ip` 私有原始参考图；
- API key、Cookie、浏览器Profile；
- 含隐私的原始录屏；
- 缓存和临时Base64请求体。

最终包只保留已验收的派生人物资产和必要证据片段。
