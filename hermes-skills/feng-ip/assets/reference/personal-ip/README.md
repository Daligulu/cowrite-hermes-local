# 峰峰个人 IP 素材说明

来源目录：

`/root/Documents/Obsidian Vault/30-Assets/PersonalBrand/峰峰IP-Canon/`

本目录镜像了 21 张用户提供的个人 IP 原始素材，包括单动作姿势、生活方式场景和三张 contact sheet。

使用规则：

- 图生图时选择 1–2 张最相关参考图；
- 第一张负责动作，第二张负责身份/正脸/服装；
- 参考图只通过 ApiYi Nano Banana HTTPS 请求内的 Base64 `inlineData` 发送，不创建公网链接；
- 不直接把原 PNG 贴进最终图片；
- 不复制原背景或九宫格布局；
- 人物 Canon 以 `references/ip/feng/ip.md` 为准；
- 新增或替换原始素材后，应重新同步本目录并做 SHA-256/文件数核验。
