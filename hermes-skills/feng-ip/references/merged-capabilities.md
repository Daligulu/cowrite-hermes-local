# 合并能力清单

`feng-ip` 合并了原 `feng-illustrations` 与 `feng-ip-workflow` 的有效能力，并删除重复或过时规则。

## 唯一事实来源

- 人物 Canon：`references/ip/feng/ip.md`
- 构图：`references/composition-patterns.md`
- Shot Config：`references/shot-config.md`
- 风格：`references/styles/quirky-sketch.md`
- Prompt：`references/prompt-template.md`
- QA：`references/qa-checklist.md`
- Nano Banana 接口：`references/apiyi-nano-banana.md`

## 已保留能力

- 中文文章/段落分析与认知锚点提炼
- 单图和多图 Shot Config
- 低科技怪诞隐喻和具体物件故事动线
- 峰峰个人 IP 双参考图选择与身份锁定
- ApiYi Nano Banana 2/Pro 图生图
- 21 张个人 IP 原始素材
- 14 张历史构图校准示例
- 无字底图 + 本地准确中文标签
- 人物、构图、风格、文字四层 QA
- 飞书 `MEDIA:` 交付
- Agnes 明示式应急回退

## 未保留为独立规则的旧文件

旧 `feng-ip-canon.md` 已被内容更完整的 `references/ip/feng/ip.md` 吸收；旧 `style-dna.md` 已被 `references/styles/quirky-sketch.md` 吸收；旧 feature-parity 文档由本文件替代。删除这些重复文件可避免两套 Canon 或风格规则发生漂移。

历史示例仅用于校准信息密度、留白和怪诞隐喻，不是人物身份参考，不得复刻构图或引入旧角色。
