# 白板讲解类正文图的二次收敛

适用于“峰峰站在白板前讲解观点”等 16:9 正文配图。首轮常见问题不是人物身份漂移，而是**人物过大 + 近白比例过高**：画面看似干净，却偏头像海报，信息主体不够集中。

## 首轮检查

同时执行：

1. 视觉 QA：人物是否约占画宽 10–20%，白板/隐喻是否为主视觉，人物是否通过指示棒或手势承担信息动作。
2. `scripts/check_color_balance.py --strict`：不能因“整体很白”就跳过。近白比例高于 88% 也属于失败。
3. 检查无文字、乱码、数字、Logo、水印及参考图贴片。

## 定向重生成

若人物过大或近白比例略高，保留首轮输出并追加一段收敛指令，不要换模型或无目的重试：

- 人物明确缩至画宽 12–16%，放在画面边侧；人物外套不能成为最大色块。
- 白板占画宽约 68–72%、画高约 62–68%，成为主视觉。
- 加粗白板框、核心物件、箭头等黑色抖动线稿；不靠新增色块降低近白比例。
- 近白目标 82–86%，场景仍以白底黑线为主。
- 不增加面板、便利贴、标题、数字或额外流程节点。
- 指示棒必须精确指向核心变化节点，开放手势只作辅助。

## 通过标准

- 严格配色门禁无失败；
- 人物身份、暖桃肤色、白 hoodie、深海军蓝夹克稳定；
- 三秒内读懂白板隐喻；
- 人物承担讲解动作但不压过白板；
- 输出 MIME、尺寸和文件可打开性均验证通过。
