# 透明贴纸与网格交付

用于峰峰九宫格表情、动作包、贴纸切图和飞书交付。该流程补充正文配图工作流，不改变人物 Canon。

## 1. 网格源图规范化

- 模型生成的正方形九宫格常见尺寸为 2048×2048，不能整除 3。
- 切图前先居中裁切或缩放到最接近且可被 3 整除的尺寸；例如 2048→2046，再按固定阅读顺序切成 9 张 682×682。
- 先切无标签源图；中文标签板另行本地合成。不要从带中文标签的成品板切透明贴纸，否则去背后文字会漂浮或遮挡人物。
- 候选总览优先分别生成 6 张候选，再由本地脚本组成严格等宽 3×2；不要依赖模型自己画网格和数字。

## 2. 两级去背

### 闭合轮廓、纯白背景

可从边缘对近白像素做四连通洪泛。只处理与边缘连通的背景，保留闭合轮廓内的白色 Hoodie、眼白和牙齿。

### 白色衣物触及裁切边缘、浅灰或浅蓝均匀背景

亮度阈值会沿底边进入白 Hoodie，产生透明孔洞。改用自适应主体分割：

1. 从四条边估计中性背景色；
2. 用颜色距离、色度和暗色像素建立确定前景；
3. 用主体外轮廓填充暖白衣物等浅色内部；
4. 用 GrabCut 或等价分割清理与人物相连的浅色光晕；
5. 过滤小背景连通块，但保留问号、爱心、眼泪等有效独立元素；
6. 边缘轻度羽化，输出 RGBA PNG。

不要通过简单降低近白阈值来追求“更多透明”；这通常会误删 Hoodie、书页、纸张和牙齿。

## 3. 真实 Alpha 验收

仅检查 `RGBA` 模式或“至少一个透明像素”不够。必须同时满足：

- 每套恰好 9 张；
- 尺寸、格式与命名顺序正确；
- 每张存在真实透明像素；
- 把 PNG 叠到棋盘格上生成 QA 总览并视觉检查；
- 背景基本全部露出，无大块浅灰/浅蓝残底；
- 白 Hoodie、眼白、牙齿、脸、手、书页、纸张、电脑、背包完整；
- 问号、爱心、眼泪等独立元素未被过滤；
- 无透明孔洞、矩形残底、明显光晕和主体破损。

程序门禁通过但棋盘格视觉检查失败时，结果仍不得交付。

## 4. 飞书传输

- 保留无损 PNG 作为本地、Obsidian 和归档事实来源。
- 飞书 `im +messages-send --image` 的单图上限为 5 MB；发送前预检大小。
- 不透明的大图超过上限时，另存高质量 JPG 传输版（建议 quality 92、subsampling 0、optimize），不要覆盖无损 PNG。
- 透明贴纸必须保持 PNG；若超过上限，优先无损优化或合理缩小尺寸，不能改成 JPG。
- 批量逐图发送要记录每张回执；只补发失败项，避免全量重发造成重复。
