# 内容创作：配图风格偏好 + 三件套查重（长期用户偏好）

> 触发：给微信文章/X 推文做「贴图 + 微头条 + 头条文章」三件套时要读本文件。全文链路见 `wechat-article-to-cowrite-3deliverables.md`。

## 配图风格：按内容类型选（用户偏好，2026-09-01 确认）
- **科技 / AI / 新闻类内容**（AI 模型、视频生成、芯片、开源事件等）→ 默认 **3D 质感**：低饱和冷灰蓝/奶白渐变、主体意象如悬浮电视机 + 无限循环符号 / 发光河流 + 视频播放按钮 + 秒表，上/下留大片空白供排版。此风格干净、有未来感，适合科技叙事。
- **萌宠 / 生活 / 可爱产品类** → 默认 **日系清新 / 摄影写实**：低饱和、奶白背景、淡蓝淡绿点缀、留白充足。如「399 美元小鸭子机器人」这类软萌内容。
- **山水 / 传统文化类** → 国风水墨。

### 用户中途加风格约束时（常见）
用户常像这样中途补一句：「微信贴图用 3D 质感配图，微头条也是」。**这类风格约束适用于所有带图的交付物**，不是只改贴图页——微头条、头条正文、封面都要对齐同一风格。收到后别只重做贴图，把其余带图交付物一起对齐。

### 生成后必检（防返工）
`vision_analyze` 检查：① 无任何文字/字母/数字/标志；② 上、下留白充足（供排版）；③ 无瑕疵/乱码/跑偏主体；④ 主体完整清晰。合格才 copy 到 `/root/.cowrite/worker-assets/` 再 `cowrite_upload_asset`。

## 三件套：先查重、别盲建（2026-09-01 实操）
用户常在同一主题上**重复发起**「生成三件套」指令。动身前先 `cowrite_list_pages` 按主题关键词筛同题页：
- 若该主题**已存在且 revision ≥2**（内容完整、可能已落地）→ **先读回现状告诉用户**，再确认要「用现成」还是「重做一版」。之前那版可能已 revision 5、贴图已发公众号草稿箱、头条已投递手机——盲目重建会污染工作区。
- 用户要「重做」时（很常见，尤其当天已做过）→ 这是确认后的有意识动作：用**不同标题（如加 V2）+ 不同切入点**与旧版并存，**不覆盖旧页**。

### 交付话术
三页均为 revision 1 草稿、未发布、未群发；明确写「确认后我可再排版进公众号/投递草稿箱」。页面标题 + Cowrite 主入口必须用 markdown 链接（用户要求链接必须能直接点开，勿放代码块/反引号）。贴图给 `MEDIA:/root/.cowrite/worker-assets/<file>.jpg` 内联预览。
